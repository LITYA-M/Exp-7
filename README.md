# EXP – 5: STUDENT ENROLLMENT SYSTEM
# AIM:

To analyze and design a Student Enrollment System that allows students to register for courses, view available courses, enroll in selected courses, and manage their enrollment details efficiently.

# SRS (Procedure):

1.Identify the functional and non-functional requirements of the Student Enrollment System.
2.Identify the main actors such as Student, Staff, ERP, and Admin.
3.Define the major functions such as student login, viewing courses, course enrollment, enrollment confirmation, and course management.
4.Prepare the Software Requirements Specification (SRS) based on the identified requirements.
5.Design the required UML diagrams to represent the structure, behavior, and interaction of the system.
6.Verify the diagrams to ensure that they correctly represent the Student Enrollment System.
